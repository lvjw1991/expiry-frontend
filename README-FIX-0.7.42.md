# v0.7.42 修改说明

基础版本：v0.7.34

## 修改范围
1. 点货详情页、点货新增页日期选择时，移动端日期输入框字体保持 16px，降低 iOS 聚焦自动放大的风险。
2. viewport 设置为禁止用户缩放。
3. 增加 iOS gesture 事件、双击和快速双击触摸结束事件拦截，尽可能阻止双指捏合及双击缩放。

## 保持不变
- 未修改后端、API、数据库及点货业务逻辑。
- 未修改日期选择器的数据格式和选择流程。
- 未主动修改分页、状态统计、扫码流程或 PC 页面布局。
- 未加入后续版本的日期文字重复显示修复。

## 验证状态
源码已修改并打包；当前未执行前端构建，也未完成 iPhone/Android 实机验证。iOS 浏览器对缩放限制存在系统版本差异，需实机确认。
