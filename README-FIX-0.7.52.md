# v0.7.52 更新说明

基于 v0.7.51 增加商品批量分类功能：

- 商品管理页新增“批量分类”入口。
- 新增商品批量分类页，默认筛选未分类商品。
- 支持按商品名称/条形码搜索，并按未分类、已分类、全部商品筛选。
- 支持勾选商品后统一设置分类，保存前二次确认，成功后刷新列表。
- 对接 `GET /api/products/category-management` 与 `PATCH /api/products/category/batch`。
- 未修改后端、点货保存、收货单分类继承、效期记录分类继承逻辑。

构建验证：本次环境中 `npm ci` 超时，`npm run build` 因缺少 `vue-tsc` 无法完成；需在有完整依赖的环境运行构建验证。
