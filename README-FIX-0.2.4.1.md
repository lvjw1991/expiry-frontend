# v0.2.4.1 - 手机有效期日历红点修复

修复手机有效期日历日期有记录但没有显示红点的问题。

## 修复
- 日历红点现在以 `/api/records/calendar` 返回的记录是否存在为准。
- 与当前筛选条件下的商品列表保持一致：某日期有返回记录就显示红点。
- 不再因为 `stock = 0` 而隐藏红点。
- 对 `expiryDate` 做前10位日期归一化，兼容 `YYYY-MM-DD` 和带时间的日期字符串。
- 今日到期数和日期列表也使用相同的日期归一化。

PC `/api/records` 不变，手机仍只使用 `/api/records/calendar`。

本环境未能安装 npm 依赖，因此未完成本地生产构建验证；请在项目环境执行 `npm install` 后再 `npm run build`。
