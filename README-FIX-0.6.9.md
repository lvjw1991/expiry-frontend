# v0.6.9

Mobile 点货 UI / 数据字段调整：

1. 点货商品列表的「待点货 / 异常 / 通过」状态页签不再显示右侧件数，避免分页导致数量不准确。
2. 点货商品列表右侧数量改为显示订单箱数 `orderQty`，单位为「箱」。不根据箱规反算。
3. 点货新增页面中「商品名称」单独占一整行。
4. 点货详情页顶部增加返回按钮，固定返回 `/m/check` 点货列表页。
5. 点货详情页「应到个数」字段使用 `total`，改为可编辑数字输入。保存时：
   - PASS：`actualQty = total`，`damageQty` 默认 0；
   - FAIL：使用用户填写的 `actualQty` 和 `damageQty`。
6. API 前端请求类型同步增加 `total` 字段。

保留 v0.6.8 的 iPhone 列表页横向溢出修复，以及有效期逐个删除、无「全部清空」按钮的改动。

构建说明：当前 ZIP 未包含完整 node_modules，因此无法在当前环境执行 `npm run build`；源码修改已完成。
