# v0.2.3 手机有效期 + 扫码优化

## 手机有效期
- 今日到期数量
- 月历：有库存的有效日期显示红点
- 点击日期显示商品卡片
- 商品卡片显示图片、商品名、Barcode、有效期、库存、确认状态、处理状态
- 整卡进入手机详情
- 详情执行确认存在 / 找不到
- 找不到后仍可执行正常销售 / 促销 / 报损
- 支持确认状态、处理状态、Category 筛选
- 操作后返回列表时保留日期和筛选条件并重新查询

## 手机扫码
- 点击按钮后才打开摄像头
- 使用后置摄像头
- 尝试自动放大/对焦区域
- 支持手电筒（设备支持时）
- 扫描成功自动关闭摄像头并填充 Barcode
- 不支持 BarcodeDetector 时保留手工输入

## PC
- PC 登录、PC 菜单和 PC 页面不改

## 启动
```bash
npm install
npm run dev
```

手机扫码使用 HTTPS，例如 `https://192.168.1.105:5173/m/login`。
